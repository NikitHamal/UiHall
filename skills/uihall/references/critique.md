# Critique rubric

Score each 1–5, but **report changes, not scores**. Every point must name a reference id and a
concrete value.

| Lens | Ask |
|---|---|
| Purpose | Can you say the screen's one job in a sentence? Does the layout serve it? |
| Hierarchy | Is there one dominant element? What's the second read? Is the primary action obvious? |
| Density | Too many things competing? Too sparse to be useful? Compare to the closest reference. |
| Type | How many sizes/weights? Is the scale consistent? Line length, leading, tracking? |
| Colour | One accent? Status vs brand separated? Every text pair ≥ 4.5:1? |
| Spacing | Is there a rhythm (4/8)? Are related things closer than unrelated things? |
| Consistency | Radii, icon style, button styles, alignment edges. |
| States | Empty, loading, error, long text, many items. |
| Motion | Does each animation explain something? Durations and easing sane? Reduced motion? |
| Originality | Does it look like the average? What one move would make it specific? |

## Output format

```
## Top 3 changes
1. <change> — <why, tied to IMG-xxxx/VID-xxxx> — <concrete values>
2. …
3. …

## Polish
- …

## What's already working
- …
```

Use `before_after` to find redesigns of the same kind of screen — they show which fixes matter.
